# התור — המנות שממתינות לשליחה

כל קובץ כאן הוא **המנה של יום אחד**, ושם הקובץ הוא התאריך:
`2026-08-04.md` יישלח ב-4 באוגוסט ב-12:00, ולא ביום אחר.

## איך כותבים מנה

קובץ אחד, וכל הודעה מופרדת מהבאה בשורה שכולה שלושה סימני אחוז:

```
🗓 המנה היומית — 4 באוגוסט 2026
1️⃣ מחקר ראשון...
%%%
2️⃣ מחקר שני...
%%%
4️⃣ עשר מילים באנגלית
```

חמש הודעות זה המבנה הקבוע: שלושה מחקרים, עשר מילים, שיעור Claude Code.
כל חלק חייב להישאר מתחת ל-4096 תווים — זו המגבלה של טלגרם להודעה אחת.

## מי שולח

[.github/workflows/daily-digest.yml](../../../.github/workflows/daily-digest.yml)
רץ כל יום ב-09:00 UTC (12:00 בישראל), ומפעיל
[tools/send-digest.sh](../../../tools/send-digest.sh).

⚠️ **למה לא רוטינת הענן של Claude:** סביבת הענן עוברת דרך proxy עם רשימת
דומיינים מותרים, ו-`api.telegram.org` לא ברשימה. כל ניסיון משם מוחזר עם
`curl: (56) CONNECT tunnel failed, response 403` — גם ב-curl וגם ב-WebFetch.
נבדק ואומת ב-2 באוגוסט 2026. אל תנסה שוב.

## כשהתור מתרוקן

הסקריפט שולח התראה כשנשארו שתי מנות או פחות, ועוד אחת ביום שאין בו קובץ.
למלא מחדש: לפתוח VS Code ולכתוב לקלוד **"מלא את התור"**.
