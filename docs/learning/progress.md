## מה איתן כבר יודע
_(אני מעדכן כאן אחרי כל שיעור — כדי לא לחזור על מה שכבר ברור)_

- Anthropic היא החברה שבנתה את Claude, במיקוד בטיחות.
- **ההבחנה מודל/מוצר ברורה לו** — קלט אותה מהר, כולל שדפדפן ומחשב
  מריצים את אותו מוח.
- יודע ש-Claude Code רץ מקומית ולכן יש לו גישה לקבצים.
- יודע ש-ChatGPT בנוי באותו מבנה (מודל בפנים, מוצר מסביב).
- **מכיר את סולם המודלים** — Haiku · Sonnet · Opus · Fable, לפי כוח ומחיר.
  התאים נכון משימה קלה ל-Haiku ומשימת כתיבה ל-Sonnet.
- ראה את המחירים בפועל ($1 עד $10 ל-1M טוקנים).

## מונחים שכבר הוסברו
_(מונח שמופיע כאן — מותר לי להשתמש בו בלי להסביר שוב)_

- **מודל / model** — קובץ המספרים. המוח.
- **מוצר** — העטיפה שנותנת למודל ידיים. Claude Code, claude.ai.
- **Anthropic** — החברה.
- **Haiku · Sonnet · Opus · Fable** — סולם המודלים, כולל מזהים ומחירים.
- **טוקן** — הוזכר במחירים בלבד ("מחיר ל-1M טוקנים"). **עדיין לא הוסבר
  מה זה.** שיעורים 4 ו-8.
- **חלון הקשר / context window** — הופיע בטבלה כמספר בלבד. לא הוסבר. שיעור 5.

## נקודות לחזור אליהן
_(משהו שלא נקלט טוב, או שאלה שנשארה פתוחה)_

- **בלבול בין שם מודל לכתובת אתר.** סיווג את `claude.ai` כמודל (שיעור 1).
  כלל האצבע שניתן: "אם אפשר להיכנס לזה — מוצר". לוודא בשיעור 6.
- **רפלקס "משימה גדולה ← המודל הכי חזק".** בחר Fable למשימה ארוכה
  במקום Opus (שיעור 2). ההבנה נכונה, שיקול העלות חסר. שיעור 3 נוגע
  בזה ישירות — לבדוק שם אם הופנם.
- **נוטה לענות על חלק מהשאלה.** קרה בשיעור 1 ובשיעור 2. בשיעורים
  הבאים: לוודא שהתרגיל הוא באמת פריט אחד, או לסמן במפורש כמה
  תשובות מצופות.
